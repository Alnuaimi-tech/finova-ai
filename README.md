# FINOVA AI

**A bilingual (English / العربية) financial wellness platform for UAE students and young adults.**

🌐 **Live app:** https://finova-ai.base44.app

FINOVA AI helps young people in the UAE understand and improve their money. They enter their monthly income, expenses and savings in AED and get a transparent 0–100 Financial Health Score, personalized next steps, and an AI coach grounded in real UAE living costs. The core flow works fully in English or Arabic, with right-to-left layout.

## Features

- **Financial Health Score (0–100)**: a transparent, weighted scoring model with a Low / Medium / High risk tier and an on-screen breakdown of every component
- **Insights, action plan and 3-month prediction**: generated by a rule-based engine using UAE-relevant thresholds, in English or Arabic
- **What-If Scenario Simulator**: see how cutting rent or discretionary spending would change your score
- **Future Projection**: 1 / 5 / 10-year savings trajectory, with an LLM-written explanation of what those amounts could cover in the UAE
- **AI Coach**: a conversational agent (`finova_analyst`) grounded in the user's own numbers. It replies in English or Arabic, and is instructed to educate rather than give buy/sell advice
- **Learn hub**: 8 UAE-specific modules (50/30/20, emergency fund, BNPL & credit cards, student benefits, extra income, rent, transport, subscriptions), an investment-readiness check and a compound-growth simulator
- **Market & Virtual Portfolio**: live ADX data via TradingView's licensed widgets, and practice investing with virtual funds. DFM stocks are clearly labeled as demo data, because licensed real-time DFM data isn't available at this project's scale
- **PDF financial report** and a **shareable score badge**. The badge shows the score and risk level only, never income
- **Contact form → email**: messages are stored and emailed to the support inbox
- **Admin analytics** for usage tracking

## How the score works

Implemented in `src/lib/financialEngine.js` → `calculateFinancialScore()`:

| Component | Weight | Full marks when |
|---|---|---|
| Savings rate | 35% | saving ≥ 20% of income |
| Expense ratio | 28% | expenses ≤ 70% of income |
| Discretionary (shopping) spending | 27% | lower is better; 0 marks at ≥ 20% of income |
| Emergency fund | +0 to +10 bonus | savings cover ≥ 3 months of expenses |

The result is clamped to 0–100: under 40 is High Risk, 40–69 is Medium Risk, and 70 or more is Low Risk.

**Why rules and not a trained model?** A financial score should be deterministic and explainable: the same inputs always give the same score, and every point can be traced. An LLM is used where natural language adds value (the coach and the projection narrative).

## Architecture

- **Frontend:** React + Vite + Tailwind, React Router, Recharts, Framer Motion (`src/`)
- **Internationalization:** a custom `LanguageContext` (`src/lib/LanguageContext.jsx`) with matching English and Arabic dictionaries. Stored values (such as risk levels and professions) stay in English, and translation happens at the display layer, so the database stays consistent
- **Backend platform:** managed database, auth and serverless (Deno) functions
- **Backend functions** (`base44/functions/`):
  - `getMarketData`: authenticated market-data fetch (Twelve Data API)
  - `sendContactMessage`: validates and stores contact messages, then emails the support inbox
  - `askFinanceQuestion`: authenticated LLM finance Q&A endpoint
- **Scheduled workflow:** `RefreshMarketPrices` refreshes a price cache on a timer, with a distributed lease/lock and daily credit budgeting, to respect third-party rate limits
- **AI agent:** `finova_analyst` (`base44/agents/`)
- **Data model** (`base44/entities/`), 6 entities with role-based / row-level access control: `FinancialProfile`, `VirtualHolding`, `MarketDataCache`, `ContactMessage`, `AppEvent`, `User`
- **PDF report:** generated client-side with jsPDF (`src/lib/generatePDFReport.js`)

## Security

- All financial inputs are validated in the form and bounded in the schema (0 – 10,000,000 AED)
- A user's `FinancialProfile` is readable only by that user (or an admin)
- Backend functions require authentication
- Security scans were run before and after fixes

## Language coverage

Fully bilingual (EN/AR with RTL): Home, Analyze, Dashboard (all tabs), the Learn module titles, and navigation. Other pages and the PDF report are currently English. See *Roadmap*.

## Running this locally

1. Clone the repository
2. Install dependencies: `npm install`
3. Create an `.env.local` file with:

```
VITE_BASE44_APP_ID=your_app_id
VITE_BASE44_APP_BASE_URL=your_backend_url
```

4. Run the app: `npm run dev`
